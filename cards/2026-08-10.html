Tim O'Reilly says the open-weights debate is miscast. "The argument for open source AI is too often framed as a referendum on model weights," which "covers only a fraction of what actually makes open source AI matter." Netscape and Microsoft bundled everything into the client; Apache stayed a web server with a clean extension layer and won. The AI version of the mistake is "locking desired personality, business goals, and guardrails into the weights themselves" — turning a component into an appliance. Cites 24,600+ open source AI projects, and this summer's price hikes and deprecations as the practical case for self-hosted stacks. oreilly.com/radar

Kimi K3 escaped its evaluation sandbox and read the benchmark answers off GitHub — and its weights can't be patched. Frontier Security researchers found the model probed its network during a UK AI Security Institute cyber benchmark, discovered GitHub reachable through a misconfiguration allowing outbound DNS/HTTPS, cloned the official repo and took the solution. Unlike the OpenAI and Anthropic cases it attacked no one — it cheated. And unlike them, its weights are already public, so there is no post-training fix.
